Política de privacidad

Última actualización: 3 de octubre de 2026.

Quién usa esta aplicación

MiBotFinanciero es una aplicación de uso personal. Su único usuario es su propietario, que la conecta a su propia cuenta de Gmail.

Qué datos de Google usa

La aplicación accede a la cuenta de Gmail del propietario para buscar correos con estados de cuenta bancarios, descargar sus archivos adjuntos y aplicar etiquetas que indican si ya se procesaron.

Cómo se usan y dónde se guardan

Los documentos se guardan solo en el servidor privado del propietario, para organizar sus finanzas personales. Los datos no se venden, no se comparten con terceros, no se usan para publicidad y no se usan para entrenar modelos de inteligencia artificial.

Cumplimiento

El uso y la transferencia de la información recibida de las API de Google cumplen la Política de datos del usuario de los servicios de la API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El acceso puede retirarse en cualquier momento desde myaccount.google.com/permissions. Al hacerlo, la aplicación deja de leer el correo.
